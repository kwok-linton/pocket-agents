# Contributing

**External code pull requests are not accepted at the moment, at least not into `main`.** Pocket Agents is source-available and offered under commercial licenses, so we can only merge code we hold the rights to license.

Please use [GitHub issues](https://github.com/kwok-linton/pocket-agents/issues) for bug reports, ideas, questions and commercial license requests. When reporting a bug, include your OS, the Claude Code / Codex CLI version, the phone and browser, and what you expected to happen. Never paste tokens, private URLs, session IDs or transcripts of private work.

---

**暂时不接受外部代码 PR，至少 `main` 分支不接受。** Pocket Agents 是源码可用软件，并对外提供商业授权，因此只能合并我们有权对外授权的代码。

问题反馈、功能建议、使用疑问和商业授权申请，请提交 [GitHub issue](https://github.com/kwok-linton/pocket-agents/issues)。报告问题时请写明系统版本、Claude Code / Codex CLI 版本、手机和浏览器，以及你预期的结果。不要粘贴 token、私有地址、会话 ID 或私人工作的对话内容。
